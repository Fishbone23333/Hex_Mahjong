# 海克斯麻将

一个面向线下麻将牌局的网页端全局海克斯抽取系统。房间内的抽卡、场地效果、随机牌面和倒计时会通过 WebSocket 实时同步。注册账号后，还可以创建仅自己可管理的 DIY 海克斯和私人卡池。

## 本地运行

```bash
npm install
npm start
```

默认服务地址为 `http://127.0.0.1:3000/`。

- 大厅：`http://127.0.0.1:3000/`
- 账号与卡池工坊：`http://127.0.0.1:3000/studio.html`

需要 Node.js 22.16 或更高版本（SQLite 一致性备份使用该版本起提供的备份接口）。账号、会话、私人卡牌和私人卡池默认保存在 `data/hex-mahjong.sqlite`；`data/` 已加入 `.gitignore`，不会推送到 GitHub。

## 账号与私人卡池

1. 在卡池工坊注册或登录账号。
2. 创建私人 DIY 卡牌，并为卡面保留“所有节点、仅开局、有人胡牌后、牌局后期”这一默认出现节点信息。
3. 创建 1～5 个自定义抽取节点，再选择官方卡牌和自己的私人卡牌；选中 DIY 卡牌后，逐张勾选它可以出现的节点。
4. 官方卡牌继续按官方节点标签分配，DIY 卡牌严格按卡池中勾选的节点分配，不会再根据卡片默认信息自动改写。
5. 回到大厅创建房间时选择私人卡池。房间会冻结一份卡池快照，加入房间的玩家会看到同样的节点和卡牌效果。

私人卡牌和卡池只能由所属账号查看、编辑和选用，不会加入网站的公共官方图鉴。它们进入房间后会显示给同房间玩家，以便共同执行线下规则。

## 邮箱绑定与密码找回

注册仍只需要用户名和密码，邮箱为可选设置。登录后在“我的 → 账号设置 → 绑定邮箱”验证当前密码、接收并填写六位邮箱验证码；验证成功后邮箱才可用于找回密码。未绑定邮箱的账号无法使用密码找回，同一个邮箱只能绑定一个账号。

登录页点击“忘记密码”，输入已绑定邮箱，邮件提供 15 分钟有效且只能使用一次的重置链接。重置成功后所有设备需重新登录，私人海克斯和卡池保留。绑定验证码 10 分钟有效、最多尝试 5 次；更换邮箱或修改密码会作废旧的找回链接。

服务器配置 `SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURE`、`SMTP_USER`、`SMTP_PASS`、`MAIL_FROM`；可通过 `MAIL_PUBLIC_BASE_URL` 固定邮件中的站点路径。QQ 邮箱使用 `smtp.qq.com:465`、`SMTP_SECURE=true`，`SMTP_PASS` 为授权码。未配置完整 SMTP 参数时邮箱服务不开放，注册登录仍可使用。配置与验证步骤见 [邮箱绑定与找回密码](deploy/邮箱绑定与找回密码.md)，真实凭据仅放在服务器环境文件或已忽略的本地 `.env`。

## 测试

```bash
npm test
```

测试包含卡牌冲突、最近三局权重、倒计时、大逃杀、安全规则、结算，以及账号和私人卡池端到端流程。

`npm run test:email` 使用本地 SMTP 接收器验证绑定和密码找回，不向真实邮箱发信；覆盖旧数据库迁移、验证码过期/尝试限制、邮箱唯一性、持久化发信限流、重置并发/重放、会话撤销和私人数据保留。

新增安全回归还覆盖异常 Cookie、复杂卡池预算、账号配额、密码校验并发/限流/竞态、成员接管、房号复用、分页、正式环境 Cookie/Origin，以及 WAL 备份恢复。

## 安全与部署

- 每账号默认 200 张私人牌、30 个卡池、10 个有效会话；内容写入按账号/IP/全站限频，列表每次最多 100 条，工坊分批加载全部内容。
- 密码使用有界异步 scrypt；卡池搜索有匹配剪枝与 12000 步/20ms 预算，超限拒绝并保留原牌局。
- 同成员新页面接管旧连接；锁屏席位保留 10 分钟，仍计入四人限制。所有人主动退出立即解散，10 分钟无牌局操作删除规则保留。
- 私人 API 统一禁止缓存，脚本 CSP 使用哈希并禁止内联事件属性；正式环境要求配置 HTTPS `ALLOWED_ORIGINS`。
- `npm run backup`：在设置 `HEX_DB_PATH` 后生成一致性 SQLite 备份，默认保留最近 14 份；备份目录由 `HEX_BACKUP_DIR` 指定。
- `npm run release:prepare`：生成白名单发布目录及摘要清单，不包含本地数据库、凭据或日志。

正式环境参数见 [deploy/hex-mahjong.env.example](deploy/hex-mahjong.env.example)，低权限服务、Nginx 限流、备份与监控配置和切换/恢复步骤见 [安全部署与恢复](deploy/安全部署与恢复.md)。部署时请根据自己的域名、路径和服务账号调整示例文件；不要把真实环境文件、数据库或部署记录提交到 Git。服务重启会结束内存房间。

## 主要文件

- `index.html`：网页界面与前端交互。
- `server.mjs`：房间、实时同步、抽卡和计时服务。
- `studio.html`：账号、私人 DIY 卡牌和私人卡池工坊。
- `lib/account-store.mjs`：SQLite 账号、会话、卡牌和卡池数据层。
- `cards.json`：服务器使用的官方卡池和卡牌元数据。
- `hex_mahjong_hexes.md`：完整海克斯图鉴和规则说明。
- `更新日志.md`：项目更新记录。

闪卡制作使用独立的 `holo-card-studio` 工具，工具仓库不作为本项目运行依赖提交。
